## CI 构建失败修复（logs_89250610508）

- **根因**：合并上游时 package.json 加了 `@deepseek-ai/dsh-authorization`，但 `npm install --package-lock-only` 未写入 lock（该包不在 node_modules，npm 静默跳过报 "up to date"），导致 CI `npm ci` 报 EUSAGE「Missing from lock file」，Windows/Linux 双平台在安装依赖步骤失败。
- **教训**：合并时新增依赖后 `npm install --package-lock-only` 不可靠（本地无该包时静默跳过），必须用 `npm ci --dry-run` 复核 lock 同步；或从上游 lock 提取完整条目手补。
- **修复**：提交 3311da7，从上游 lock 提取完整条目（version/resolved=registry.npmmirror.com/integrity/peerDependencies）补入顶层 dependencies + node_modules 条目；`npm ci --dry-run` exit 0 验证通过。
